# AI Passport — Vibe Typeless

这是 [FoloToy/ai-passport](https://github.com/FoloToy/ai-passport) 的 fork。当前开发在 `feature/vibe-typeless`：把 Passport 做成 Typeless 的一键说话麦克风，给 vibe coding 用。

- 固件：BLE IMA-ADPCM 麦、确定/下/上三键、VIBE 状态页
- Mac 桥：`tools/mac-bridge/` 把 PCM 写入 `BlackHole 2ch` 并轻按 F19
- 构建、刷机、验收：[docs/development/vibe-typeless.zh_CN.md](docs/development/vibe-typeless.zh_CN.md)

上游 `main` 保持干净基线，不要在 `main` 上堆功能。
