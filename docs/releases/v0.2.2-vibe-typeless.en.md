# Vibe Typeless 0.2.2

This release provides a ready-to-use macOS Bridge and the matching ESP32-C3 firmware.

## Download

Open the [latest GitHub Release](https://github.com/xiabill/ai-passport/releases/latest) and download:

- `FoloVibeBridge-macos.zip` — macOS companion app.
- `FoloToy-AI-Passport-full.bin` — merged firmware image for the AI Passport.

The Bridge requires macOS 13 or newer. The package is not notarized. If macOS blocks the first launch, Control-click the app in Finder, choose **Open**, and confirm.

## Install and configure the Bridge

1. Unzip `FoloVibeBridge-macos.zip` and move `FoloVibeBridge.app` to `/Applications`.
2. Open the app and follow the setup checks.
3. Grant Bluetooth, Accessibility, and Input Monitoring permission to `FoloVibe Bridge`.
4. Install BlackHole 2ch and select it as the microphone input in Typeless and Doubao.
5. In Bridge Settings, choose the same base key that Typeless uses (`Fn` or `F19`). Choose the Doubao key used by Doubao's toggle mode; the default is Right Option.
6. Enable auto reconnect if you want the device to reconnect after sleep or a Bluetooth interruption.

The Bridge uses one Passport connection at a time. To switch between Macs, use **Release device to another Mac** on the current Mac, then let the other Bridge reconnect.

## Button actions

| Device action | Result |
| --- | --- |
| OK single click | Start/stop Typeless Dictate |
| OK double click | Start Typeless Translation |
| OK long press | Start Typeless Ask anything |
| UP | Start/stop Doubao |
| DOWN | Stop the active input and press Return |

The Doubao edit gestures select all and delete the current focused text field. Typeless Translation adds Shift and Ask anything adds Space to the configured base key.

## Audio behavior

The microphone stream is sent over BLE to the Mac and written to BlackHole 2ch for the input method. Connection, recording, stop, edit, and send cues are generated on the Passport and played through its I2S → ES8311 → speaker path; the Mac does not substitute its own speaker for these hardware cues.

## Flash the firmware

Only flash the merged image from this release. Use the [browser flasher](https://ai-passport.folotoy.cn/tools/web-flasher/) or ESP-IDF tooling. The image is written from offset `0x0`:

```bash
python -m esptool --chip esp32c3 \
  -p /dev/cu.usbmodemXXXX -b 460800 \
  write_flash 0x0 FoloToy-AI-Passport-full.bin
```

Do not run `erase-flash` on an existing device. The merged image preserves the protected identity and Recovery regions. After flashing, reconnect the Bridge and wait until the status page says the device is ready.

## Troubleshooting

- **No button mapping:** confirm the Bridge status says audio and button-event notifications are both enabled. Then make sure Typeless and Bridge use the same key (`Fn`/`F19`) and that Accessibility/Input Monitoring is enabled.
- **No hardware cue:** reconnect the device and check the Bridge-ready sound first. If it is still silent, use the Bridge logs and the device serial monitor to check the ES8311/I2S path.
- **No Typeless audio:** choose `BlackHole 2ch` as Typeless's microphone and confirm the Bridge has Bluetooth permission.
- **Device not found:** wake the Passport, confirm it advertises as `FoloVibe-*`, and keep only one Bridge connected while testing.

For the complete protocol, power rules, development build, and recovery constraints, see the [development guide](../development/vibe-typeless.en.md).
