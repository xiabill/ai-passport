# Vibe Typeless 0.2.2

这个 Release 提供可直接使用的 macOS Bridge，以及配套的 ESP32-C3 固件。

## 下载

打开[最新 GitHub Release](https://github.com/xiabill/ai-passport/releases/latest)，下载：

- `FoloVibeBridge-macos.zip`：macOS 伴侣程序。
- `FoloToy-AI-Passport-full.bin`：AI Passport 合并固件。

Bridge 需要 macOS 13 或更高版本。程序未经过 Apple 公证；如果 macOS 第一次阻止打开，请在 Finder 中对 App 点按住 Control，选择“打开”，再确认。

## 安装和配置 Bridge

1. 解压 `FoloVibeBridge-macos.zip`，把 `FoloVibeBridge.app` 拖到 `/Applications`。
2. 打开程序，按应用内设置检查逐项操作。
3. 在“系统设置 → 隐私与安全性”中给 `FoloVibe Bridge` 打开蓝牙、辅助功能和输入监控权限。
4. 安装 BlackHole 2ch，并在 Typeless、豆包输入法中选择它作为麦克风输入。
5. 在 Bridge 设置中选择与 Typeless 一致的基础键（`Fn` 或 `F19`）。豆包选择豆包“免按模式”使用的按键，默认是右 Option。
6. 如果希望设备在休眠或蓝牙短暂中断后自动恢复，打开自动重连。

同一台 Passport 同时只接受一台 Mac。换 Mac 时，在当前 Mac 选择“释放设备给另一台 Mac”，再让另一台 Mac 上的 Bridge 自动连接。

## 按键功能

| 设备操作 | 功能 |
| --- | --- |
| 确定单击 | 启动/停止 Typeless 听写 |
| 确定双击 | 启动 Typeless 翻译 |
| 确定长按 | 启动 Typeless 随便问 |
| 上键 | 启动/停止豆包输入法 |
| 下键 | 停止当前输入，并发送回车 |

豆包编辑手势会对当前获得焦点的输入框执行全选并删除。Typeless 翻译会在基础键上追加 Shift，随便问会追加 Space。

## 音效说明

麦克风声音通过 BLE 发送到 Mac，再写入 BlackHole 2ch 供输入法使用。连接、录音开始、录音结束、编辑和发送提示音均由 Passport 设备端生成，并通过设备的 I2S → ES8311 → 硬件喇叭播放；不会改由 Mac 喇叭代播。

## 刷写固件

只刷本 Release 提供的合并固件。可以使用[在线刷机工具](https://ai-passport.folotoy.cn/tools/web-flasher/)，也可以使用 ESP-IDF 工具。固件从 `0x0` 写入：

```bash
python -m esptool --chip esp32c3 \
  -p /dev/cu.usbmodemXXXX -b 460800 \
  write_flash 0x0 FoloToy-AI-Passport-full.bin
```

已有设备不要执行 `erase-flash`。合并镜像会保留设备身份和 Recovery 保护区域。刷完后重新连接 Bridge，等待状态页显示设备已就绪。

## 常见问题

- **按键没有映射：**确认 Bridge 状态显示音频通知和按键事件通知都已开启；再确认 Typeless 与 Bridge 使用同一个键（`Fn`/`F19`），并检查辅助功能/输入监控权限。
- **硬件没有提示音：**重新连接设备，先测试连接提示音；仍无声时查看 Bridge 日志和设备串口日志，检查 ES8311/I2S 链路。
- **Typeless 没有声音：**确认 Typeless 的麦克风选择 `BlackHole 2ch`，并确认 Bridge 已获得蓝牙权限。
- **找不到设备：**唤醒 Passport，确认它广播为 `FoloVibe-*`，测试时只保留一个 Bridge 连接。

完整的 BLE 协议、省电规则、开发构建和 Recovery 约束见[开发教程](../development/vibe-typeless.zh_CN.md)。
